# فیلم‌نما · آموزشگاه آزاد سینمایی

> اولین و تنها کارگاه سینمایی با مدرک بین‌المللی در غرب تهران

صفحهٔ اصلی (Homepage) رسمی **آموزشگاه آزاد سینمایی فیلم‌نما** — یک تجربهٔ وب کاملاً سینمایی با حال‌وهوای سالن سینمای آرت‌هاوس ایرانی: نور اسپات‌لایت در دل تاریکی، پردهٔ مخمل، فریم فیلم ۳۵ میلی‌متری و بلیت سینما.

طراحی‌شده برای مخاطب ایرانی (RTL، موبایل‌فرست) با هویت بصری طلایی-زرشکی روی نویر گرم — متفاوت از قالب‌های ژنریک SaaS.

## اجرای محلی

```bash
# نصب وابستگی‌ها
bun install

# راه‌اندازی سرور توسعه
bun run dev
# → http://localhost:3000

# بررسی کیفیت کد
bun run lint

# بیلد تولید
bun run build
```

> نیازمند [Bun](https://bun.sh) (یا npm/yarn/pnpm) و Node.js ۱۸+.

## دیپلوی روی Vercel

این پروژه برای Vercel بهینه‌سازی شده است:

1. ریپو را در GitHub فورک/کلون کنید.
2. در [vercel.com](https://vercel.com) یک پروژهٔ جدید بسازید و ریپو را متصل کنید.
3. Vercel به‌صورت خودکار Next.js را شناسایی می‌کند — نیازی به تنظیم دستی نیست.
4. `Build Command`: `next build` (پیش‌فرض) · `Output Directory`: `.next` (پیش‌فرض)
5. Deploy.

> توجه: صفحهٔ فعلی کاملاً استاتیک است و از دیتابیس استفاده نمی‌کند. اگر بعداً ویژگی‌های داده‌محور اضافه کنید، باید `DATABASE_URL` را به یک دیتابیس سازگار با Vercel (مانند Vercel Postgres) تغییر دهید، زیرا SQLite روی فایل‌سیستم موقتِ سرورلس کار نمی‌کند.

## ساختار پوشه‌ها

```
src/
├─ app/
│  ├─ layout.tsx        # RTL + فونت‌های فارسی + متادیتا
│  ├─ page.tsx          # ترکیب سکشن‌های صفحهٔ اصلی
│  └─ globals.css       # پالت نویر + انیمیشن‌های سینمایی
├─ components/
│  ├─ ui/               # کامپوننت‌های shadcn/ui
│  └─ filmnama/         # کامپوننت‌های اختصاصی فیلم‌نما
│     ├─ data.ts        # محتوای واقعی برند
│     ├─ header.tsx     # هدر شناور
│     ├─ hero.tsx       # هیرو سینمایی + بلیت CTA
│     ├─ marquee.tsx    # نوار اسکرول‌شونده
│     ├─ about.tsx      # تخته کلاکت
│     ├─ courses.tsx    # کارت‌های فریم ۳۵mm
│     ├─ teachers.tsx   # اساتید به سبک تیتراژ
│     ├─ screening.tsx  # اتاق نمایش
│     ├─ articles.tsx   # مجلهٔ سینمایی
│     ├─ testimonials.tsx
│     ├─ contact.tsx    # باجهٔ بلیت‌فروشی + USSD
│     └─ footer.tsx     # THE END
└─ lib/
public/images/          # تصاویر سینمایی (هیرو، اساتید، مقالات)
```
